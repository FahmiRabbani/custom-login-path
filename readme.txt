== Description ==

Plugin untuk menyembunyikan URL login WordPress. Ganti `wp-login.php` dan `wp-admin` dengan URL login kustom.

== Installation ==

1. Upload plugin ke folder `/wp-content/plugins/`
2. Aktifkan plugin dari halaman 'Plugins' di dashboard WordPress
3. Buka Settings → Hide WP Login URL untuk mengatur URL login kustom

== Frequently Asked Questions ==

= Bagaimana jika lupa URL login? =
Nonaktifkan plugin via FTP atau File Manager.
