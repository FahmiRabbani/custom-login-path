Ganti URL login WordPress Anda dari wp-login.php ke tautan khusus yang Anda tentukan. Tingkatkan keamanan situs Anda dari bot dan serangan brute-force.

== Description ==

**Custom Login URL** memungkinkan Anda untuk:
- Menyembunyikan halaman `wp-login.php` dan `wp-admin`
- Mengalihkan URL login ke tautan yang Anda tentukan, misalnya: `example.com/loginku`
- Menambahkan pengaturan di menu *Settings > Custom Login URL*
- Menonaktifkan fitur kapan saja melalui toggle di pengaturan

== Installation ==

1. Unggah folder `custom-login-url` ke direktori `/wp-content/plugins/`
2. Aktifkan plugin melalui menu 'Plugins' di WordPress
3. Masuk ke *Settings > Custom Login URL* untuk mengatur slug login Anda
4. Simpan dan gunakan URL baru untuk login ke situs Anda

== Frequently Asked Questions ==

= Bagaimana jika saya lupa URL login baru saya? =
Nonaktifkan plugin melalui FTP atau file manager untuk kembali ke URL login default (`wp-login.php`).
